# Event Coverage fonts

Unmodified variable WOFF2 subsets served locally so the Event Coverage viewer retains its typography when Google Fonts is unavailable. Each family includes Latin and Latin Extended; Cormorant Garamond includes roman and italic. The browser downloads only the subsets used on the page.
